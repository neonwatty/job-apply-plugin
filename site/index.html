Job Apply Plugin turns Claude Code into a job application assistant. Extract your profile once, reuse confirmed answers, and let uncertain or sensitive fields come back to you for review before you submit manually.

Four skills

Remember trusted answers, set preferences, discover opportunities, and apply.

/job-apply:job-apply

Fill out applications automatically

  • One-time profile setup from your resume (PDF, DOCX, or TXT)
  • Multi-platform: LinkedIn Easy Apply, Greenhouse, Ashby, Lever, Rippling, Workday
  • Smart field mapping from your profile to form fields
  • Visible automation in your Claude in Chrome session
  • Stops at final review so only you can submit
/job-apply:answer-memory

Reuse answers without losing control

  • Stores profile data and reusable answers locally
  • Distinguishes confirmed, inferred, missing, and sensitive answers
  • Requires separate consent before remembering sensitive values
  • Saves resumable progress without copying answer values
  • Migrates the legacy profile non-destructively
/job-apply:job-search

Find jobs where you have an advantage

  • Searches using your saved titles and filters
  • Finds jobs at companies where you have connections
  • Identifies jobs with hiring managers listed
  • Searches LinkedIn, Hacker News, and Twitter/X
  • Results saved to ~/.claude-job-searches/ as Markdown
/job-apply:job-preferences

Save reusable search preferences

  • Sets target titles and minimum base salary
  • Records remote-work and time-range preferences
  • Filters out unwanted titles and seniority levels
  • Stores preferences with your local profile
  • Updates selected settings without replacing the rest

Requirements

One browser integration required.

Claude Code

The CLI that runs the plugin and orchestrates the entire workflow.

Claude in Chrome

The visible default for browser navigation, authenticated sessions, form filling, and local file uploads.

Optional fallback

If already configured, Playwright may help with a site-specific iframe or control Chrome cannot reach. It is not required.

Install

Add the plugin and start applying.

Install from the Claude Code plugin marketplace, then invoke /job-apply:job-apply with a job URL. Your profile and explicitly confirmed answers are stored locally and reused when their scope still matches. 

claude plugin marketplace add neonwatty/job-apply-plugin
claude plugin install job-apply@neonwatty-plugins

# Then in Claude Code:
/job-apply:job-apply

Safety first

You stay in control at every step.

Only you submit

Every application stops at final review with a field summary. You inspect the page and click Submit or Send yourself.

Never enters passwords

The plugin pauses for login, password, CAPTCHA, MFA, or account creation so you can handle it yourself.

Never enters payment info

Premium features and paid prompts are skipped automatically.

Sensitive answers stay deliberate

Using a sensitive answer once never stores it automatically. Remembering it requires a separate explicit choice, and future use is still reconfirmed.

Changing ATS controls

If Chrome cannot reach a site-specific field, the plugin reports it and leaves it for you unless an optional fallback is already configured.

Privacy and support

Know what stays local, and where to get help.

Plaintext local store

Your profile, answer bank, minimal history, and resumable sessions live under ~/.job-apply/. Protect it like a resume; never attach its files to a public issue.

No plugin telemetry

The repository defines no telemetry service. Information is shared with third-party sites only when you direct Claude to use it in browser or search workflows.

Friendly, redacted support

Use a guided GitHub issue form for setup help, ATS failures, or feature requests.
