# P06 ownership lifecycle

The reference audit reruns the frozen task-evidence and non-release contracts on synthetic Git repositories. It establishes the existing fail-closed behavior; it does not accept ownership handoff or P06 implementation.

Implementation must additionally verify exact reviewed predecessor-to-successor file handoff through the registered product checker, retain unreleased ownership, reject forged or concurrent handoffs, and validate coordinator metadata throughout planning, source, evidence and receipt commits. Source input hashes and historical evidence remain immutable. No task is accepted from a partial implementation.
