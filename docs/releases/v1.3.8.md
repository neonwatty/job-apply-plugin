# Job Apply v1.3.8

- Overview, Jobs, and Needs Attention show the saved next step for an application. When a job is ready for an agent, Companion lets you copy the command for Codex or Claude Code and paste it into your chat.
- Companion shows the form checks recorded for the current review and identifies steps you still need to take in the browser. After you submit on the employer’s site, confirm in Companion to record the submission locally.
- Résumé fact review makes it easier to see where saved facts came from. If a job changes elsewhere while you’re closing it, Companion keeps your selected closing outcome while you refresh.
- This release includes Windows attempt broker groundwork. The supported marketplace platforms are macOS Apple Silicon and Linux x64.
