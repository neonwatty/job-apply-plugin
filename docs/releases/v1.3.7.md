# Job Apply v1.3.7

- The default Codex and Claude Code marketplaces now install the validated stable release. Job Apply and its optional Companion ship from the same Git commit. Existing users can refresh their marketplace to update. [Installation and update commands](https://github.com/neonwatty/job-apply-plugin#installation)
- The opt-in preview marketplace follows `main`. Use the commit SHA to identify a preview build. [Preview install commands](https://github.com/neonwatty/job-apply-plugin#try-preview)
- Windows Store groundwork adds native file locking, private file permissions, and safer file updates. Marketplace installs support macOS Apple Silicon and Linux x64 with Node.js 22 or newer.

[Full changes since v1.3.6](https://github.com/neonwatty/job-apply-plugin/compare/v1.3.6...v1.3.7)
