# Job Apply v1.3.9

- Job Apply and Companion now run on Windows x64 with Node.js 22 or newer. Install or update through the standard marketplace in Codex or Claude Code. The Windows runtime runs without Python.
- On first use, Job Apply creates a native Store or opens a validated native Store. If you have data in a legacy Store, Job Apply leaves it untouched. You can choose a fresh Store location and optionally import a legacy profile with `store init --legacy-profile PATH`.
- Companion gives in-flight saves time to finish during Windows shutdown. On restart, it can recover from an interrupted save while preserving the last committed data.
